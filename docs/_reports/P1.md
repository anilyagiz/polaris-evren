# P1 — Gerçek tarayıcı E2E raporu

## Komutlar

```powershell
cd scripts\browser_e2e; npm install; npx playwright install chromium; cd ..\..
node scripts/browser_e2e/run.mjs            # sahte LLM (deterministik), fixture.html
node scripts/browser_e2e/run.mjs --live     # gerçek LLM (backend/.env), gerçek siteler
# seçenekler: HEADED=1 (izle), SKIP_BUILD=1 (out/ext'i yeniden kullan), LIVE_ONLY=<senaryo>
# deney: --live --tool-choice-required  (backend'e tool_choice="required" yaması, ürün koduna dokunmaz)
```

Çıktılar: `scripts/browser_e2e/out/` (ekran görüntüleri, `results.json`, `live-results*.json`,
`backend.log`, `console.log`, `run.log`). Uzantı `out/ext`'e derlenir (`extension/dist`'e dokunulmaz).

Akış: vite build → (sahte LLM `fake_llm_browser.py`, `scripts/e2e/fake_llm.py`'yi değiştirmeden yeniden kullanır)
→ gerçek backend `uvicorn backend.main:app` (boş port, geçici `ASSISTANT_DB`) → Playwright Chromium +
`--load-extension` → panel sayfası sekme olarak, test sayfası ayrı pencerede → ayarlar `chrome.storage`
(mock kapalı, backend portu) → sohbet arayüzünden mesaj → DOM üzerinde doğrulama.
