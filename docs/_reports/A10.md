### BUG 1 - protocol_robustness: gecersiz JSON text frame baglantiyi kapatir (1006)
- Dosya: `backend/orchestrator.py` `serve_connection` (`await websocket.receive_json()`).
- Belirti: `"this is { not json"` gonderilince `JSONDecodeError` dis `except Exception` ile yakalanir, "WS okuma dongusu bitti" loglanir ve soket hata frame'i gonderilmeden kapanir. INTERFACES §10: "hata -> error frame, asla cokme".
- Oneri: `receive_text()` + `json.loads` ile ayri try; hata olursa `{"type":"error","request_id":null,"message":"Gecersiz JSON"}` gonder ve `continue`.

### BUG 2 - desktop_flow_fake_session: desktop.snapshot trace'i hic yayilmiyor
- Dosya: `backend/tools/desktop.py` `_emit_snapshot_trace`.
- Belirti: `ctx.emit_trace(step)` duz `dict` ile cagriliyor, ama emitter `TraceStep` bekliyor (`step.to_event` / `to_wire`): log `AttributeError: 'dict' object has no attribute 'to_wire'`. Sonuc: `shot:/shots/...` kanitli adim panele ve SQLite'a gitmez (senaryo 6'nin "ekran goruntuleriyle zaman cizelgesi" kabul kriteri). Akis yine de calisir (snapshot/click/type, duzenleyicide "Merhaba" gorunuyor, /shots PNG donuyor).
- Oneri: `from backend.trace import make_step` ile `make_step("executor", decision, why, evidence=[f"shot:{snapshot['shot']}"], tool={"name":"desktop.snapshot","args":{}}, latency_ms=...)` yayinla.
- Yan bulgu: `desktop.snapshot` `{"ok":True,"data":...}` sarmali yerine cplak snapshot donuyor; orchestrator "sozlesme disi sonuc" uyarisiyla kurtariyor (WARNING). Sarmali ekle.

### BUG 3 - browser_search_highlight: hicbir trace'te `ref:` kaniti yok
- Dosya: `backend/agents/executor.py` (`_resolve`, `FINISH_SCHEMA`) ve `backend/orchestrator.py` (`action.evidence`).
- Belirti: Arac cagrisi trace'leri `evidence=[]`; `finish` semasinda `evidence` alani olmadigindan `ExecutorAction.evidence` hep bos, responder'a `evidence=[]` gider. PROTOCOL §6'daki "ref: panel tiklayinca highlight eder" ozelligi (demo 3) hic veri almaz.
- Oneri: ref argumani olan araclarda (click/type/highlight/read) `_emit(..., evidence=[f"ref:{ref}"])`; `FINISH_SCHEMA`'ya `evidence: array<string>` ekle ve `ExecutorAction(evidence=...)` doldur.
