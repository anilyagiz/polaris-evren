# A9 raporu - kişisel tool'lar

Orchestrator zaten `_reminder_loop` ile `reminders.due()` çağırıyor (await edilebilir, her kayıt bir kez döner:
`{id,text,due_iso}`). Ek güvenli seçenek (gönderim başarısızsa hatırlatma kaybolmaz):

    from .tools import reminders
    async def _send_notify(rec):
        await self._send({"type": "notify", "text": f"Hatırlatma: {rec['text']}", "spoken": f"Hatırlatma: {rec['text']}"})
    self._reminder_task = asyncio.create_task(reminders.start_watcher(_send_notify, interval=30))

`send_notify` exception fırlatırsa kayıt `unmark()` ile tekrar beklemeye alınır. Elle kullanım:
`await reminders.unmark([rec["id"]])`. Kapanışta task.cancel().

Not: orchestrator `memory.search`'e `{"query", "limit": 3}` yolluyor; handler artık `limit` kabul ediyor (şemada yok).
